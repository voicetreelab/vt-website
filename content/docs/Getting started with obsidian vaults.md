---
title: Getting Started with Obsidian Vaults
description: Quick start guide for using Voicetree with Obsidian vaults. Install, open your vault, and start creating nodes.
---

1. Install VoiceTree: `brew tap voicetreelab/voicetree && brew install voicetree`
2. Open VoiceTree and select your vault folder. Your files stay as local markdown. Edit them in Obsidian or VoiceTree, they stay in sync.
3. Start speaking or right-click to create nodes
