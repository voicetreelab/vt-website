---
title: Voicetree for Tree Style Terminal Tabs
description: Use Voicetree as a graphical interface for organising many terminal tabs with one-click native terminals and attached notes.
---

Voicetree can be used as graphical interface for organising many terminal tabs. You can open a native-terminal with one click. Each terminal will have a node attached to it where you can save notes, or spawn child-terminals.
